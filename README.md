
# Welcome to SeaVerity

Gather proof from the sea. Get rewards.

At sea, your work is real. SeaVerity turns that work into proof — and proof into rewards. Go out, gather the record, and get rewarded for what you bring back.

No stories. No guesswork. Just proof from the sea, and a reason to gather it.

Download seaverity.apk and start collecting.

The installable file is always `seaverity.apk`.   
Tags match the app `versionName` with a `v` prefix (for example `v1.0.0`).
